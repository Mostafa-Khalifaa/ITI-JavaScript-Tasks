## 📌 About
This repository documents my journey through the **JavaScript (Client-Side)** course at the **Information Technology Institute (ITI)**. It contains daily labs, assignments, and mini-projects that demonstrate core programming concepts, DOM manipulation, Object-Oriented Programming (OOP), and modern Asynchronous JavaScript.

## 🚀 Topics Covered
* **Core JS:** Variables, Hoisting, Coercion, Loops, and Conditions.
* **Objects & Arrays:** String API, Math Object, Date Object, and Array Methods.
* **DOM & BOM:** Selecting elements, Event Handling, Creating/Cloning nodes, Window & Location objects.
* **Advanced JS:** Regular Expressions (Regex), Error Handling, and Form Validation.
* **Modern JS (ES6+):** Arrow Functions, Destructuring, Spread/Rest Operators, Classes, Modules.
* **Async Programming:** Promises, Fetch API, and Async/Await.
